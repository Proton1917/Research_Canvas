# 科研画布原型要求

依据 2026-10-24 的 [开源项目调研](research_canvas_open_source_review_2026-10-24%20%281%29%281%29.pdf)，Research Canvas 的工作对象包含研究长文、数学公式、用户想法、AI 讨论、图片、证据和关系线。用户在同一画布中组织这些对象，保留讨论分支及来源，并逐步形成可引用的研究结果。

## 编辑与研究协作

内容与画布编辑采用 BlockSuite 提供的文档模型和编辑组件。页面和画布视图共享内容；文稿片段可以在不同画布中出现，每个画布保存独立的布局信息。Dim0 的画布动作和 ThoughtDAG 的上下文连线为 AI 协作提供实现参考，研究关系、来源锚点与修订状态由 Research Canvas 的统一数据模型表达。

AI 的阅读范围由选定段落、节点或画布区域确定，界面展示提交给模型的上下文。对原文和画布对象的写入先提供可查看的修改结果，再由用户确认，并支持撤销。自由连线可以直接保存；需要论证时，再补充关系类型、对应对象、适用条件、反例和出处。

每条批注记录所属文稿、版本和片段位置。原文修订后，系统尝试重新定位；定位失败时显示失效状态，并保留旧版本来源。跨学科关系可以记录为启发性类比、待验证结构候选或已验证结果，状态随证据修改。

## 首轮验收

选用一篇包含长论证、公式、引文及可争议推论的研究稿，在同一份工作数据上顺序执行以下流程。

| 操作 | 验收事实 |
| --- | --- |
| 将长文放入画布，添加框和独立想法 | 正文可编辑，缩放和移动后内容结构保持完整 |
| 选定公式或推论启动 AI 讨论 | 讨论关联精确片段，并在相应位置显示 |
| 从同一讨论分叉两个研究方向并比较 | 分支独立；各次调用所使用的上下文可以查看 |
| 连接两个学科的概念并研究关系 | 保存具体对应对象、成立条件、反例及来源 |
| 修改已被讨论的原文，再打开旧批注 | 批注重定位成功，或显示明确的失效锚点 |
| 确认研究想法并导出文稿与关系图 | 导出结果保留来源、版本、讨论历史及可编辑内容 |

当前项目提供编辑源码和 Rust 后端。后端接口及验收说明见 [HTTP 接口约定](api.md) 与 [后端说明](backend.md)，开发接入方式见 [贡献说明](../CONTRIBUTING.md)。上述六项作为统一产品的验收要求。
