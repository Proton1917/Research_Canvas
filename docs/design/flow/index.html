怎么看这张图

每张截图对应一个页面或关键状态，连线说明通过什么操作到达下一步。

  • 蓝线双向：显示进入和返回操作
  • 橙线单向：表示状态推进或页面跳转
  • 实线：已实际执行的关系
  • 虚线：源码依据或尚未验证

缩远后的色块

深色表示入口，描边标出关联较多的界面。选中后突出相邻节点，其余内容变淡。

  1. 选择截图查看大图、状态和操作关系，再次点击可放大定位。
  2. 点击详情中的操作，跳到相应界面。
  3. 拖动画布或滚轮平移，按住 Ctrl / ⌘ 滚轮缩放。
  4. 点击小地图定位；按 Esc 或点击“怎么看”取消选择。
