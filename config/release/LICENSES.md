# 随附代码的版权与许可

Research Canvas 自有代码采用根目录 `LICENSE` 中的 MPL-2.0。迁入代码与依赖的原始版权、许可条件和免责声明保留在本目录。

`src/editor/` 的编辑与画布代码对应 BlockSuite、TOEVERYTHING 的许可文本；内部绘图、几何、遍历和交互代码对应本目录各组件命名的文本。`src/ui/` 的界面基础代码对应 Open Claude UI 的 MIT 文本。后端研究算法所参考和适配的代码告知也随附在本目录。

`DEPENDENCIES.txt` 列出构建使用的 Rust 与前端依赖名称、版本、许可声明，以及依赖分发材料中的版权和许可文本。Poppler 由用户单独安装。

源代码及完整来源记录：[Research Canvas](https://github.com/Proton1917/Research_Canvas)。发行包根目录的 `SOURCE_COMMIT` 指明本次构建对应的提交。
