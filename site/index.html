本机运行

数据在你的电脑里，模型由你来选

数据只存本机

  • 服务开在 127.0.0.1:8787，用浏览器打开
  • 工作区、文稿、PDF、讨论和历史版本都在解压目录的一个 SQLite 文件里
  • PDF、Excel、PPT 的文字由程序内置解析，不上传

接你自己的模型

  • 支持 Anthropic Messages 和 Chat Completions 两种接口协议
  • 点击「设置 → 模型服务」，填写地址、API Key 和模型
  • 设置保存在本机，保存后立即生效
  • 还没有模型服务？用合作中转站接入

开源

  • 项目代码采用 MPL-2.0 许可
  • 每个发行包注明构建所用的源码提交
  • Rust 后端 + 网页界面，可以自己从源码构建

接入 AI

讨论、改写和画布提案都要接一个模型服务

导入、编辑、画布和导出在本机完成。使用 0.1.4 的「设置 → 模型服务」填写接入信息，选择模型后即可发起讨论。

合作中转站推荐

rest2build

一个 Key 同时支持 Research Canvas 用到的两种接口，注册后在控制台自助创建。

Chat CompletionsAnthropic Messages模型列表接口
前往 rest2build 获取 Key

也可以换成任何支持这两种接口之一的模型服务，改第 2 步里的地址和模型名即可。画布提案要求模型支持工具调用。

1
创建 API Key在 rest2build 或你选择的模型服务控制台创建 Key，准备好该服务的 API 基础地址。
2
打开模型服务设置启动 Research Canvas，点击顶栏「设置 → 模型服务」。使用 rest2build 时选择 Chat Completions，填写下面的 API 基础地址，再粘贴 API Key。 
https://www.ai.rest2build.lol/v1
3
读取目录并选择模型点击「测试连接并读取模型」，选择默认模型和启用模型，也可手动填写模型 ID。需要读取图片时，将服务支持视觉的模型加入图像模型列表。目录状态会显示在模型选项中。
4
保存并发起讨论点击「保存」后立即生效。选取研究材料，发送一个问题，通过运行状态和回答确认生成结果。连接失败时可以展开中文提示下的详细原因。

API Key 随设置保存在本机 config/server.local.toml 中，升级时连同数据一起迁移。
